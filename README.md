# 张普朝 · 个人作品集（静态站点）

硬件装置研发 / 创客教育装备方向的一页式个人作品集：个人简介、能力矩阵、12 个精选项目技术档案、71 项装置全景目录、工作方法、教研资产、履历与联系方式。

**纯静态、零依赖、离线可用**——不用装 Node、不用打包，双击 `index.html` 就能打开；上传到任意静态托管即可上线。

---

## 两个版本（同一份内容，两种表达）

| | V1 · 工业规格书 | V2 · 时装编辑（ISSUE 01） |
|---|---|---|
| 入口 | `index.html` | `v2/index.html` |
| 风格 | 米白图纸底 + 墨黑 + 安全橙，技术图册感 | 象牙纸 + 墨黑 + 钴蓝；Bodoni Moda 衬线 × 宋体标题，杂志版式 |
| 项目展示 | 纵向图文交错的 12 个案例 | 暗场横向 pinned 画廊：近满屏卡片、彩色实拍、衬线标题 |
| 装置图录 | — | **20 张整机实拍图录**：三栏错落版面 + 大图灯箱（←/→ 切换） |
| 能力 | 表格化矩阵 + 刻度条 | 衬线大字清单 + 钴蓝刻度 |
| 全景 | 深色表格 | 纸面索引 + 黑色读数卡（点击切换） |
| 动效 | 克制的入场淡入 | 标题分行升起、数字滚动、色块翻转、横向推进；无粒子、无光标特效 |
| 适合 | 打印/投递/正式场合（稳重、可读性最高） | 线上分享/个人品牌（杂志感、第一眼冲击力） |

两版共用同一套内容源：`content/*.json` → `assets/js/data.js`；V2 通过 `../assets/js/data.js` 与 `../assets/img/` 引用，所以**改一次内容，两版同时更新**。
首页右上角的 `V2 · NEON` 与 V2 顶栏的 `V1` 可以互相切换。

## 二、本地查看

直接双击 `index.html`。

> 之所以把数据编译成 `assets/js/data.js` 而不是用 `fetch('content/*.json')`，是因为浏览器在 `file://` 协议下会拦截本地 fetch。用 `<script>` 加载没有这个限制，所以离线双击也能完整显示。

需要本地起服务时（可选）：

```powershell
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 三、怎么改内容

### 1. 改联系方式 / 署名（最常改）

编辑 `content/facts.json` 里的 `identity`，例如：

```json
"identity": {
  "name": "张普朝",
  "email": "你的邮箱@example.com",
  "role": "K-12 科创装置研发与交付 · 独立研发者（北京）",
  "tagline": "..."
}
```

然后重新生成数据：

```powershell
python tools\build_data.py
```

> 首页右侧数据卡、页脚、联系区文案在 `index.html` 里，可直接改文字（不影响 JS 逻辑）。
> 微信 / GitHub 等链接在 `index.html` 的 `.contact__links` 中替换 `href`。

### 2. 改精选案例

编辑 `content/cases.json` 中对应案例的字段：

| 字段 | 说明 |
|---|---|
| `title` / `tagline` / `category` / `year` | 标题与一行概述 |
| `summary` | 卡片上的 80–120 字摘要 |
| `problem` / `solution` | 弹层里的"问题 / 方案"两段 |
| `highlights` | 3 条关键点（每条 `title` ≤10 字、`desc` ≤45 字） |
| `metrics` | 3 个量化指标 |
| `stack` / `role` / `deliverables` | 技术栈 / 我的角色 / 交付物 |
| `images` | 由 `images.json` 自动注入，不用手填 |

改完同样执行 `python tools\build_data.py`。

### 3. 加 / 换项目图片

1. 把图片（jpg/png）压到长边 ≤1600px、<350KB，命名 `{caseId}-{序号}.jpg`，放进 `assets/img/`；
2. 在 `content/images.json` 的对应 caseId 数组里加一条：

```json
{ "file": "assets/img/lingtong-4.jpg", "w": 1200, "h": 1600, "caption": "舱盖内侧主控板接线" }
```

3. 重新生成数据。

`{caseId}-1` 会作为卡片主图，其余进弹层画廊。**没有配图的案例会自动显示一张"技术数据牌"**（TECH FILE + 该项目的技术栈编号清单 + 赛道/年份），不会出现空白框或"待补"字样——所以缺图不影响观感，补齐后自动切换成照片。

当前 12 个案例中有 7 个配了实拍（17 张），另外 5 个（大棚车、机械臂腰带、瓷壁敲击车、发酵桶、脑电眼镜）因为源目录里只有学生操作照/文档截图，按"画面里不出现人物"的隐私原则**故意没放图**。以后拍到设备静物照，按上面的方式补即可。

### 4. 改能力评分

`content/facts.json` → `capabilities[].level`（0–5，支持 3.5 这类小数）。矩阵顶部的 10 格刻度按 `level × 2` 点亮。
`boundaries` 是"能力边界 · 不冒充的部分"，可整段删除。

### 5. 改项目全景

`content/catalog.json`：`items[]` 每条包含 `id / title / category / track / tagline / stack / year / status`。
筛选项来自 `categories[]`（名称 + 数量），搜索框匹配标题、技术栈、赛道。

> `catalog.md` 与 `cases.md` 是给人看的校对稿，改数据后如需同步可手工更新或重跑 `tools/build_catalog.py`。

## 四、发布上线

任选其一，都是把整个 `个人作品集` 目录原样上传：

| 平台 | 做法 |
|---|---|
| **GitHub Pages** | 新建仓库 → 上传本目录全部文件 → Settings → Pages → 选分支 `/root` → 得到 `https://用户名.github.io/仓库名/` |
| **Vercel / Netlify** | 拖拽目录即可，无需构建命令，输出目录填 `.` |
| **国内静态托管**（OSS/COS/轻量服务器） | 上传后把 `index.html` 设为默认首页 |

注意：
- 目录里的 `content/`、`tools/`、`_shots/`（如存在）可以不上传，站点运行只依赖 `index.html` + `assets/`。**建议连 `content/` 一起传**，方便以后改内容。
- 如果部署在子路径（`/portfolio/`），本站全部用相对路径，无需改配置。
- 图片较多，建议开启托管方的 gzip/brotli 与长缓存；`assets/img` 内容基本不变，可缓存一年。

## 五、V2 专属说明

- **字体**：`v2/assets/fonts/` 内置 5 个拉丁字体文件（Bodoni Moda 正体/斜体、Instrument Serif Italic、Archivo、Archivo Black，均为 SIL OFL 许可），离线可用。中文大标题走系统宋体（Songti SC / SimSun / Noto Serif SC），正文走系统无衬线。
- **配色**：象牙纸 `#f4f1e9` / 墨 `#131210` / 钴蓝 `#1b2cf5`。钴蓝只出现在数字带、选中态、分数条和链接端点，全站不超过三处大面积色块。
- **版式**：三栏报纸式页眉（刊号 / 章节 / 页脚信息）、竖排 "PORTFOLIO — ISSUE 01" 书脊字、`FIG.00` 图注、纸面颗粒层；正文列宽 44–56ch，标题用 8vw 衬线。
- **摄影**：作品图保持彩色（不做统一灰度），靠统一的裁切比例和暗场背景统一；hover 时轻微放大、饱和度回升。
- **横向 pinned 画廊**：桌面端 `#work` 随纵向滚动横移 12 个项目，右上角 `01 / 12` 是进度；≤900px 自动降级为原生横向滑动（不劫持滚轮）。实现用 `viewport.scrollLeft`，不用 `transform`（避免合成层未栅格化露白）。
- **装置图录（03 / Plates）**：20 张整机实拍，三栏错落版面；点开进灯箱，支持 ← / → 与 Esc。图片按原始比例展示，JS 用 `grid-row-end: span` 做等高错落排版（窗口尺寸变化会重排）。图片走 `width/height` 属性，因此图片未加载完版面也不跳。
- **`?shot=1`**：地址后加 `?shot=1` 跳过入场与计数动画、直接显示终态，用于截图/录屏（`v2/preview/` 即此法生成）。
- **两版共享内容**：V2 读取 `../assets/js/data.js` 与 `../assets/img/`，部署时 `assets/` 与 `v2/` 必须一起上传。
- 动效与参考站的调研笔记在 `content/v2-refs.md`。

## 六、内容口径与使用说明

- **数据来源**：`D:\a本人项目文件` 下的项目归档（2022–2026），统计口径为文件级实盘，详见 `content/profile.md` 的口径说明。
- **数字说明**：71 项装置中含 33 项"整机 + 成套材料"、13 项"样机/材料不全"、23 项"仅代码或 CAD"、2 项"创意阶段"；页面图例已标明，不作夸大。
- **隐私处理**：站内不含学生姓名、学校、家长联系方式、合同金额、公司证件号等敏感信息；项目图片只选用装置与场景，**画面中出现人的照片全部剔除**（宁可缺图，用技术数据牌代替）。
- **图片版权**：均为本人项目过程实拍，用于本作品集展示；如后续商用请自行确认授权链。
- **装置图录的筛选**：`D:\a本人项目文件\项目图片` 里 24 张，剔除了 3 张非装置照（电脑屏幕、接线图、CAD 截图）和 1 张背景有学生的照片，最终收录 20 张；其中 1 张裁掉了画面下方的手臂。图注只描述"画面里是什么"（如"轮式平台 · 泵组与水箱"），不做项目归属。
- **字体**：全部使用系统字体栈（中文优先 苹方/微软雅黑，等宽优先 Cascadia/Consolas），不加载外部字体，因此离线也不掉版。
- **无障碍/性能**：支持 `prefers-reduced-motion`、键盘 Esc 关闭弹层、跳转正文链接；无第三方脚本。
